# 🤖 Telegram-бот для поиска дешёвых товаров

Telegram-бот на Python, который помогает находить товары в литовских интернет-магазинах.

## 📋 Функции

✅ Поиск товаров в интернет-магазинах:
- Pigu.lt (основной)
- Amazon (в разработке)
- Другие магазины (планируется)

✅ Учёт страны доставки (Литва и соседние страны)
✅ Быстрый поиск популярных товаров с кнопок
✅ История поисков пользователя
✅ Кэширование результатов запросов
✅ Сравнение товаров сразу по нескольким магазинам (Pigu.lt, Amazon, eBay)

✅ Вывод результатов с:
- Названием товара
- Ценой в евро
- Названием магазина
- Ссылкой на товар

✅ Сортировка по цене (от дешёвого к дорогому)

✅ Топ-5 результатов

✅ Обработка ошибок

✅ Логирование

✅ **Извлечение ТОЛЬКО реальных ссылок на товары**:
- Поиск ВСЕ теги `<a href="...">` на странице
- Фильтрация по критериям:
  - ✅ Содержат `/lt/` (литовские товары)
  - ✅ Содержат `id=` (конкретные товары)
  - ❌ НЕ содержат `search` (не поисковые ссылки)
  - ❌ НЕ содержат `sq?` (не фильтрованные)
- Конвертация относительных ссылок в абсолютные
- Связь ссылки с товаром (название + цена)
- Если НЕТ ссылки с `id=` или цены → товар не добавляется
- **БЕЗ fallback**: если нет ссылок с `id=` → пустой список

✅ **Улучшенная фильтрация товаров**:
- Исключение аксессуаров (чехлы, зарядки, кабели, защитные стекла)
- Фильтрация по релевантности запросу (все ключевые слова должны присутствовать)
- Фильтр по минимальной цене (iPhone: 500€, Samsung S: 400€, MacBook: 600€, iPad: 300€)
- Удаление дубликатов по названию
- Система релевантности: +2 балла за полный запрос, +1 за каждое слово
- Сортировка: релевантность → цена

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Конфигурация

Скопируйте файл конфигурации:
```bash
cp .env.example .env
```

Отредактируйте `.env` и добавьте токен бота:
```
TELEGRAM_BOT_TOKEN=YOUR_BOT_TOKEN_HERE
```

**Важно:** Бот выполняет реальный поиск товаров на eBay с использованием надёжных заголовков и fallback на разные регионы для обеспечения стабильности.

**Как получить токен:**
1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен в `.env`

### 3. Запуск бота

```bash
python bot.py
```

Бот запустится и начнёт слушать сообщения.

## ⚠️ Важное замечание

**Pigu.lt использует Cloudflare защиту от ботов**, которая блокирует автоматические запросы. Для полноценного парсинга требуется Selenium с headless браузером или другие продвинутые методы обхода.

Текущая реализация использует cloudscraper для попытки обхода защиты, но при блокировке возвращает демо-данные для демонстрации работы кода.

Для production использования рекомендуется:
- Настроить Selenium с ChromeDriver
- Использовать прокси/ротацию IP
- Добавить случайные задержки между запросами
- Рассмотреть использование официального API Pigu.lt (если доступен)

### 🎬 Поиск товаров на AliExpress

Бот выполняет поиск товаров на **AliExpress** с учётом страны доставки:

**Особенности поиска:**
- **Учёт страны доставки** - упрощённо считается, что AliExpress доставляет в большинство стран
- **Стабильный парсинг** - использует requests + BeautifulSoup для извлечения данных
- **Гибкая обработка** - работает даже если некоторые элементы не найдены
- **Фильтрация результатов** - только товары с названиями и ссылками

**Технические детали:**
- **URL**: `https://www.aliexpress.com/wholesale?SearchText={query}`
- **Парсинг**: Множественные селекторы для надёжности
- **Обработка цен**: Автоматическое распознавание валюты
- **Лимиты**: До 5 результатов на запрос

**Технические детали:**
- **API Endpoint**: `https://svcs.ebay.com/services/search/FindingService/v1`
- **Метод**: `findItemsByKeywords`
- **Формат ответа**: JSON
- **Лимит результатов**: 5 товаров на запрос
- **Регион**: США (GLOBAL-ID: EBAY-US)

**Настройка API:**
1. Зарегистрируйтесь на [eBay Developer Program](https://developer.ebay.com/)
2. Создайте приложение и получите **App ID**
3. Добавьте `EBAY_APP_ID=YOUR_APP_ID` в файл `.env`

**Без App ID:**
- Бот будет работать, но поиск eBay будет недоступен
- В логах появится предупреждение о отсутствии App ID

**Отладка:**
- Подробное логирование каждого метода парсинга
- Debug вывод количества найденных товаров
- HTML preview при нулевых результатах для диагностики

Примеры для поиска:
- "iPhone 13"
- "Nike"
- "Samsung"
- "MacBook"

## ℹ️ Важные замечания

### Парсинг сайтов

Некоторые сайты (особенно Amazon) защищены от парсинга и используют JavaScript для загрузки контента. Для полноценной работы может потребоваться:

- Использование Selenium + Chrome для рендеринга JavaScript
- API сервиса (например, Bright Data, ScraperAPI)
- Прокси-сервер для обхода блокировок

### Текущие ограничения MVP:

- Парсинг работает с ограничениями
- Нет кеширования результатов
- Нет базы данных
- Нет истории поисков
