# 🤖 Telegram-бот для поиска дешёвых товаров

Telegram-бот на Python, который помогает находить самые дешёвые товары в интернет-магазинах Европы.

## 📋 Функции

✅ Поиск товаров в нескольких интернет-магазинах:
- Amazon
- eBay  
- AliExpress

✅ Вывод результатов с:
- Названием товара
- Ценой
- Названием магазина
- Ссылкой на товар

✅ Сортировка по цене (от дешёвого к дорогому)

✅ Топ-5 результатов

✅ Обработка ошибок

✅ Логирование

✅ **Надёжный парсинг eBay** с 4-уровневой системой fallback:
- Основной селектор (li.s-item)
- Альтернативные селекторы (div.s-item__wrapper, div.s-item)
- Простой fallback (сырые ссылки с /itm/)
- **Гарантия**: функция никогда не вернёт пустой список если страница загрузилась

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Конфигурация

Скопируйте файл конфигурации:
```bash
cp .env.example .env
```

Отредактируйте `.env` и добавьте токен бота:
```
TELEGRAM_BOT_TOKEN=YOUR_BOT_TOKEN_HERE
```

**Важно:** Бот выполняет реальный поиск товаров на eBay с использованием надёжных заголовков и fallback на разные регионы для обеспечения стабильности.

**Как получить токен:**
1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен в `.env`

### 3. Запуск бота

```bash
python bot.py
```

Бот запустится и начнёт слушать сообщения.

### 🎬 Реальный поиск eBay

Бот выполняет реальный поиск товаров на eBay с использованием надёжных техник для обхода блокировок:

**Техники парсинга:**
1. **Основной селектор** (li.s-item) - современный стандартный селектор eBay
2. **Альтернативные селекторы** (div.s-item__wrapper, div.s-item) - для случаев когда eBay меняет структуру
3. **Простой fallback** (сырые ссылки) - если структура сильно изменилась
4. **Гарантия**: **функция НИКОГДА не вернёт пустой список** если страница загрузилась

**Защита от блокировок:**
- Надёжные браузерные заголовки для имитации обычного пользователя
- Проверка на блокировку (Pardon Our Interruption, captcha)
- Fallback на разные регионы (ebay.com → ebay.co.uk)
- Задержка между запросами (0.2 сек) для избежания rate limiting

**Обработка данных:**
- Множественные fallback селекторы для названия, цены и URL
- Цена может быть неизвестна (показывается "Цена не указана")
- Автоматическая сортировка по цене
- Ограничение до 5 результатов

**Отладка:**
- Подробное логирование каждого метода парсинга
- Debug вывод количества найденных товаров
- HTML preview при нулевых результатах для диагностики

## ℹ️ Важные замечания

### Парсинг сайтов

Некоторые сайты (особенно Amazon) защищены от парсинга и используют JavaScript для загрузки контента. Для полноценной работы может потребоваться:

- Использование Selenium + Chrome для рендеринга JavaScript
- API сервиса (например, Bright Data, ScraperAPI)
- Прокси-сервер для обхода блокировок

### Текущие ограничения MVP:

- Парсинг работает с ограничениями
- Нет кеширования результатов
- Нет базы данных
- Нет истории поисков
