📡 API ТЕХНИЧЕСКИЕ ДЕТАЛИ:

  ENDPOINT:
    https://svcs.ebay.com/services/search/FindingService/v1

  ПАРАМЕТРЫ:
    OPERATION-NAME: findItemsByKeywords
    SERVICE-VERSION: 1.0.0
    SECURITY-APPNAME: YOUR_APP_ID
    RESPONSE-DATA-FORMAT: JSON
    keywords: iPhone 13
    paginationInput.entriesPerPage: 5
    GLOBAL-ID: EBAY-US

  ОТВЕТ:
    {
      "findItemsByKeywordsResponse": [{
        "searchResult": [{
          "item": [{
            "title": ["Product Name"],
            "sellingStatus": [{
              "currentPrice": [{"__value__": "99.99"}]
            }],
            "viewItemURL": ["https://ebay.com/item/..."]
          }]
        }]
      }]
    }

⚙️ НАСТРОЙКА API (ОБЯЗАТЕЛЬНО):

  1. Зарегистрируйтесь: https://developer.ebay.com/
  2. Создайте приложение в "Application Keys"
  3. Получите Production App ID
  4. Добавьте в .env:
     EBAY_APP_ID=YOUR_PRODUCTION_APP_ID_HERE

  БЕЗ APP ID:
    • Поиск eBay будет недоступен
    • В логах предупреждение
    • Бот работает с другими магазинами
