# 🚀 Changelog - search_ebay v2.0 (Надёжный парсинг)

## 📅 Дата
10 апреля 2026

## 🎯 Цель
Сделать функцию `search_ebay` максимально надёжной и гарантировать что она всегда найдёт хотя бы какие-то товары если страница загрузилась.

## 📊 Основные изменения в search.py

### 1. Новая архитектура парсинга (4 метода fallback)

**Раньше:**
```python
items = soup.select("li.s-item")
# Если ничего не нашлось - пустой список
```

**Теперь:**
```python
# Метод 1: li.s-item
# Метод 2: div.s-item__wrapper  
# Метод 3: div.s-item
# Метод 4: сырые ссылки /itm/
# Всегда вернёт хотя бы какие-то товары!
```

### 2. Helper функции для гибкого экстрахирования данных

**Добавлены новые функции:**

- `_extract_title_from_item(item)` - название с 3 fallback уровнями
  1. h3.s-item__title
  2. любой h3
  3. любой длинный span

- `_extract_price_from_item(item)` - цена с fallback
  1. span.s-item__price
  2. span с $ € £
  3. None если не найдена

- `_extract_url_from_item(item)` - URL товара
  1. a.s-item__link
  2. первая ссылка в элементе

- `_parse_ebay_items()` - основной парсинг (метод 1)
- `_parse_ebay_items_alt1()` - альтернативный (метод 2)
- `_parse_ebay_items_alt2()` - ещё один альтернативный (метод 3)
- `_parse_ebay_fallback()` - простой fallback (метод 4)

### 3. Изменения в обработке цен

**Раньше:**
```python
if price <= 0:
    continue  # Пропустить товар без цены
```

**Теперь:**
```python
price = _extract_price_from_item(item)
# price может быть None - товар НЕ пропускается
```

**В search_products:**
```python
# Цена может быть None, используем 999999 для сортировки
price = item["price"] if item["price"] is not None else 999999
# Товары с известной ценой впереди, неизвестные - позади
all_products.sort(key=lambda p: (p.price == 999999, p.price))
```

### 4. Обновлены функции форматирования

**format_product_message:**
- При цене 999999 выводит "Цена не указана"

**format_search_results:**
- Корректно обрабатывает товары без цены

## ✅ Гарантии

✔️ **Функция НИКОГДА не вернёт пустой список** если:
- Страница загрузилась (статус 200)
- Нет блокировки ("Pardon Our Interruption", captcha)

✔️ **Множественные попытки парсинга:**
- Сначала основной селектор
- Потом альтернативные
- В конце случайные ссылки

✔️ **Гибкое экстрахирование:**
- Названия ищутся несколькими способами
- Цены могут быть неизвестны
- URL всегда требуется
