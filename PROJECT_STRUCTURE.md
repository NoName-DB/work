# 📦 Структура проекта и описание файлов

## Основной код

### `bot.py` ⭐ Главный файл бота
- Основной файл для запуска
- Обработчики команд `/start` и `/help`
- Обработчик текстовых сообщений для поиска товаров
- Использует aiogram для работы с Telegram API

**Запуск:**
```bash
python bot.py
```

### `search.py` 🔍 Логика поиска товаров
- Класс `Product` для представления товара
- Функции `search_amazon()`, `search_ebay()`, `search_aliexpress()`
- Асинхронная функция `search_products()` для поиска
- Функции формирования сообщений для вывода

**Основные функции:**
- `search_products(query)` - поиск товаров во всех магазинах
- `format_product_message(product)` - форматирование одного товара
- `format_search_results(products)` - форматирование списка товаров

### `config.py` ⚙️ Конфигурация
- Загрузка переменных окружения из `.env`
- Настройки логирования
- Параметры поиска (MAX_RESULTS, SEARCH_TIMEOUT)
- Константы для магазинов и User-Agent

**Переменные:**
- `TELEGRAM_BOT_TOKEN` - токен бота
- `LOG_LEVEL` - уровень логирования
- `DEMO_MODE` - режим демонстрации
- `MAX_RESULTS` - максимум результатов

### `logger.py` 📝 Логирование
- Настройка логирования для консоли и файла
- Ротация логов (максимум 10MB)
- Хранение логов в папке `logs/`

### `examples.py` 📚 Примеры товаров
- Класс с примерами товаров для демонстрации
- Используется в режиме `DEMO_MODE=true`
- Включает примеры: iPhone, Nike, Samsung

## Конфигурационные файлы

### `.env` 🔐 Переменные окружения (ВАЖНО: не коммитьте!)
```
TELEGRAM_BOT_TOKEN=your_token
LOG_LEVEL=INFO
DEMO_MODE=true
```

### `.env.example` 📋 Шаблон переменных окружения
- Копия `.env` для примера
- Используйте для создания своего `.env`

### `requirements.txt` 📦 Зависимости
```
aiogram==3.4.1          # Telegram API
aiohttp==3.9.1          # Асинхронный HTTP клиент
beautifulsoup4==4.12.2  # HTML парсинг
requests==2.31.0        # HTTP клиент
python-dotenv==1.0.0    # Загрузка переменных окружения
```

### `.gitignore` 🚫 Игнорируемые файлы
- `.env` и другие конфиги
- `__pycache__` и `.pyc` файлы
- Логи в папке `logs/`
- Виртуальное окружение `venv/`

## Что дальше?

### Для быстрого старта:
1. Установите зависимости: `pip install -r requirements.txt`
2. Получите токен у BotFather в Telegram
3. Создайте `.env` с токеном
4. Запустите: `python bot.py`

### Для развития:
- Читайте `API_EXAMPLES.md` для интеграции реальных API
- Смотрите `DEPLOY.md` для развёртывания на сервер
- Изучайте код в `search.py` для добавления новых магазинов

### Типичные вопросы:
**Q: Бот ничего не ищет в режиме без DEMO_MODE**
A: Это нормально - парсинг требует сложной настройки. Используйте DEMO_MODE=true или API.

**Q: Как добавить новый магазин?**
A: Добавьте функцию в `search.py` и вызовите её в `search_products()`.

**Q: Можно ли использовать в боевой системе?**
A: MVP готов, но рекомендуется интегрировать API из `API_EXAMPLES.md`.
