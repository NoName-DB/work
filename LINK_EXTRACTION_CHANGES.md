# ✨ Исправление извлечения ссылок в search_pigu

## 📋 Описание изменений

Переработана логика извлечения ссылок в функции `search_pigu()` для обеспечения получения **ТОЛЬКО реальных ссылок на товары**.

## 🎯 Основные требования

### 1. Поиск ссылок
- ✅ Найти **ВСЕ** теги `<a href="...">` на странице
- ✅ Не использовать селекторы CSS (которые могут быть непредсказуемы)
- ✅ Простой парсинг: `soup.find_all("a", href=True)`

### 2. Фильтрация по критериям
Ссылка валидна, если одновременно:
- ✅ Содержит `/lt/` (литовские товары)
- ✅ Содержит `id=` (конкретные товары, не категории)
- ❌ НЕ содержит `search` (не поисковые результаты)
- ❌ НЕ содержит `sq?` (не фильтры)

**Пример валидной ссылки:**
```
https://pigu.lt/lt/mobilieji-telefonai/apple-iphone-15?id=75500617
/lt/mobilieji-telefonai/apple-iphone-15?id=75500617
```

**Примеры невалидных ссылок:**
```
https://pigu.lt/lt/search?q=iphone           # Страница поиска (нет id)
https://pigu.lt/lt/search?q=iphone&id=123    # Поиск (содержит search)
/lt/kategorija/telefonai                     # Категория (нет id)
/lt/produktai/?sq?=filter                    # Фильтр (содержит sq?)
/en/products/iphone?id=123                   # Неправильный язык (нет /lt/)
```

### 3. Нормализация URL
- Если ссылка начинается с `http` → оставить как есть
- Если ссылка начинается с `/` → добавить `https://pigu.lt`
- Остальные случаи → добавить `https://pigu.lt/`

### 4. Связь ссылки с товаром
- 📝 **Название**: текст ссылки (`link.get_text()`)
- 💰 **Цена**: поиск в контексте:
  - Родительский элемент ссылки
  - Соседние элементы (`find_next`)
  - Регулярное выражение: `\d+[\.,]\d+`

### 5. Валидация товара
Товар добавляется ТОЛЬКО если:
- ✅ Ссылка валидна (`is_valid_product_url`)
- ✅ Найдена цена (`price > 0`)
- ✅ Цена выше минимума (`price >= min_price`)
- ✅ Название содержит все ключевые слова запроса

### 6. Обработка пустых результатов
- ❌ **БЕЗ fallback** на поисковые ссылки
- ❌ **БЕЗ mock-данных** при 403/блокировке
- ✅ Возвращать **пустой список**, если:
  - Нет валидных ссылок с `id=`
  - Нет товаров после фильтрации
  - Сайт недоступен

    return ("id=" in url_lower and 
            "/lt/" in url_lower and
            "search" not in url_lower and 
            "sq?" not in url_lower)
